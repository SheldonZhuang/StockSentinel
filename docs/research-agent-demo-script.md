# 研究 Agent 三分钟演示脚本

面向外部观众（投资者、开发者）。全程不出现任何密钥、账户或个人信息；终端只展示命令与公开数据。

| 时间 | 画面 | 旁白要点 |
|---|---|---|
| 0:00–0:20 | 股哨兵首页 → 顶部导航"公司研究" | 财报季一周几十份申报。通用大模型摘要会编数字、给不出出处。这个模块的原则是：数字和判断交给程序，模型只写解释，每句都可核对。 |
| 0:20–0:50 | 终端：`node scripts/research-ingest.mjs NVDA`，日志滚动出 8-K / 10-Q 处理 | **新财报落地。** 系统按 SEC 限速自动拉取，切成带出处的段落，同时读出财报里内嵌的 XBRL 数字，包括分部和产品线。线上由每小时的看门狗自动触发，这里手动跑给大家看。 |
| 0:50–1:20 | 终端：`node scripts/research-note.mjs NVDA FY2027Q2`，日志显示多步工具调用与"self-check: N passed" | **自动生成笔记。** 模型先检索原文、读上季指引、读公司知识库，再交稿；程序逐条核对：引文必须逐字存在，数字必须能在出处里找到。核对不过的打回重写一次，仍不过就标"待人工核对"。 |
| 1:20–2:10 | 浏览器 `/research?ticker=NVDA&quarter=FY2027Q2`：关键数字表 → 点"$96.22B"跳 SEC 原文；展开一条陈述的"出处"，显示原文链接、字符区间和逐字引文；"对照管理层指引"一节显示"上季指引约 $91.0B（上下2%），本季 $96.22B，高于指引区间上限（程序生成）" | **点出处核对。** 每个数字都能点回 SEC 原文。"是否达成指引"这类结论由程序算，不让模型判断——评估里模型确实把大小比较写反过。 |
| 2:10–2:40 | 浏览器打开 `docs/research-agent.md` 的评估表 | **评估表。** 16 份笔记、160 个金标事实，数字从 XBRL 自动取并冻结。Claude 与 Grok 数字准确率都是 100%，盲评有用性 Claude 4.59、Grok 4.06。评估里发现的问题，全部改成由程序处理，没有靠调提示词掩盖。 |
| 2:40–3:00 | 终端：`curl -X POST /v1/research/ask -d '{"ticker":"NVDA","question":"数据中心收入同比增长多少"}'`（用演示 key） | **开放给 AI 生态。** 同样的能力有 API 与 MCP 两个工具：查笔记、就一家公司提问，回答逐句带出处，核对不过的句子不返回。仅供研究参考，不构成投资建议。 |

## 准备清单

- 选一家刚出财报的公司，提前跑一遍确认笔记状态为"正式版"；
- 演示 key 用 free 档，演示结束即在管理后台禁用；
- 浏览器用无登录态窗口，避免出现个人账户；
- 终端主题调大字号，命令提前写进 history，避免现场敲错。

# 策略实验室（2026-10-24 起）

目标（用户 2026-10-24）：规模化回测选策略 → 模拟盘 → 小额实盘 → 复盘循环。

## 框架（backend/backtest/lab/）
- `data.mjs`：Tiingo 复权日线面板 + FRED DTB3 现金利率；TQQQ/QLD/SOXL 等用底层 3x/2x 日杠杆（扣 (L−1)×rf 融资成本与费率）回补到上市前；TLT/IEF/AGG/EFA/SPY 上市前用 Vanguard 共同基金收益拼接
- `engine.mjs`：日频目标权重、收盘出信号次日收盘成交（lag=1）、单边 5bp 成本、权重漂移、现金计息、交易日志
- `strategies.mjs`：均线过滤 / 波动目标 / GEM / ADM / 行业趋势 / 固定配比
- `run.mjs`：合成校验 → 全期、样本内 2000–2009、样本外 2010– → 参数网格、成本与滞后敏感性。结果在 `backtest/lab/out/`（不入库）
- `tests/strategy-lab.test.js`：执行滞后、成本、漂移、计息 + 前视检测（未来数据换噪声，过去净值不变）

## 第一批结果（2026-10-24，run1）
合成校验：TQQQ 重叠期合成年化 43.8% vs 真实 42.2%（合成偏乐观约 1.6pp/年，日跟踪误差 18bp）；QLD 25.9% vs 25.2%。

| 策略 | 全期 2000-03 起 年化/回撤 | 样本内 2000–09 | 样本外 2010– |
|---|---|---|---|
| QQQ 买持 | 7.9% / −83% | −8.6% / −83% | 18.8% / −35% |
| TQQQ 买持 | −3.3% / −100% | −49% / −100% | 40.2% / −82% |
| T1 TQQQ+200日线±2% | 13.6% / −86% | −7.4% / −86% | 27.7% / −60% |
| T5 TQQQ 波动目标40%+200日线 | 16.1% / −57% | 2.4% / −51% | 24.6% / −57% |
| T4 TQQQ 波动目标40% | 18.9% / −82% | −5.7% / −82% | 35.8% / −53% |
| M2 ADM 加速双动量 | 12.3% / −32% | 13.2% / −20% | 11.6% / −32% |
| M1 GEM | 8.6% / −34% | 9.0% / −23% | 8.3% / −34% |

结论：
1. **200 日线救不了顶部入场的 3 倍杠杆**：2000-03 起点 QQQ 在均线上方 → 满仓 TQQQ，两个月跌 75% 才触发离场（交易日志核实，非 bug）；之后 2001–2003 反复假突破又磨掉一半。均线是慢信号，3x 下"慢一步"就是 −75%。
2. 参数网格（n=100–250 × 缓冲 0–5%）样本内全部 −81% 到 −96% 回撤，**没有任何参数组合能让 TQQQ+均线熬过 2000–2002**；样本外 20–34% 年化也都差不多 → 结果稳健但不是好消息
3. **波动目标比均线更有用**：T4/T5 在暴跌前波动率先抬升，提前减仓；T5 是唯一一个杠杆方案在两个时代回撤都 ≤−57%。代价是换手 30–40 次/年（税）
4. **ADM 是唯一跨两个时代都稳定的**：样本内 13.2%、样本外 11.6%，回撤 −20%/−32%；但样本外只略低于 SPY（14.1%），优势在"不怕 2000 年"
5. 成本 0→50bp 只影响 1.4pp/年；执行滞后 0/1/2/5 天结果在 8.6%–13.6% 间跳动 → 均线策略对"哪天成交"敏感，是噪声的信号

# 研究 Agent 扩展：分阶段提示词（2026-10-21）

目标：在股哨兵现有数据管线上加一个「公司研究 Agent」。输入财报和公告，输出带出处的结构化研究笔记，附一套可复现的评估（准确率、出处质量、有用性、可靠性、延迟、成本）。
定位：真实在用的研究工具，不做独立演示；不做买卖建议，不做股价预测。
节奏：每次会话只做一个阶段。每阶段结束跑测试、更新 tasks/todo.md，把评估数字记进 docs/research-agent.md。

用法：在 D:\sheldonproject\StockSentinel 开会话，按顺序把下面的提示词逐段贴进去。

---

## 阶段 0：摸底和方案（只读，不改代码）

```
读 README.md、backend/api 下和 SEC EDGAR、OpenRouter、AI 日报相关的代码、mcp/index.js、tasks/lessons.md。
我要在现有系统上加一个「公司研究 Agent」：
- 覆盖：AI 产业链 8 家公司（MSFT、GOOGL、AMZN、META、NVDA、AMD、AVGO、TSM），以后可以扩展
- 输入：SEC EDGAR 的 10-Q、10-K、8-K（含 EX-99.1 财报新闻稿），外加现有的宏观和产业链数据
- 输出：每家公司每季一份结构化研究笔记（JSON + Markdown），每条事实都带出处（文件、段落或 XBRL 字段、链接）
- 触发：新 8-K 或 10-Q 落地时自动生成（事件驱动），也能手动按公司和季度重跑
先不要写代码。给我：1）能复用哪些现有模块；2）数据流和表结构草案；3）笔记的 JSON schema；4）分阶段计划，每阶段的验收标准；5）每月 LLM 成本估算（用 OpenRouter 上便宜的模型，设硬上限，默认每月不超过 5 美元）。
拿不准的地方列出来问我。
```

## 阶段 1：文档采集和切块

```
按阶段 0 的方案实现文档层：
- 从 SEC EDGAR 拉 8 家公司最近 8 个季度的 10-Q、10-K、8-K（EX-99.1），遵守 SEC 的 User-Agent 和限速要求
- 解析成纯文本，按章节切块（MD&A、风险因素、分部收入、资本开支、指引），保存出处元数据：公司、表格类型、提交日期、accession 号、章节、字符区间、原文链接
- 数据质量检查：缺季度、重复、解析失败、空章节，结果写日志并在管理后台可见
- 增量更新：已处理的文件不重复下载
写单元测试（解析、切块、出处字段完整性），跑全量测试通过后再交付。
```

## 阶段 2：检索和知识库（LLM Wiki 式）

```
在文档层上加检索和知识库：
- 关键词 + 向量混合检索（向量用免费或本地的 embedding，说明选型理由和成本）
- 「公司 Wiki」：每家公司一页长期知识（业务分部、主要指标口径、管理层历次指引、历史关键事件），每条都链回原文出处；新文件进来时增量更新，冲突时保留新旧两条并标注
- 检索评估：手工标 30 条问题（例：「微软 2026 财年第一季度资本开支多少，同比多少」），算 recall@5 和出处命中率
把检索指标写进 docs/research-agent.md。
```

## 阶段 3：研究 Agent 和笔记生成

```
实现研究 Agent（工具调用式，多步）：
- 工具：检索、公司 Wiki 读写、XBRL 数值查询、股哨兵现有信号和产业链数据
- 流程：抽取关键数字 → 和上季度、去年同期对比 → 对照管理层上次指引 → 总结变化和风险点 → 生成笔记
- 硬规则：每个数字必须来自 XBRL 或原文，附出处；找不到就写「未披露」，不许推测；不给买卖建议，附免责声明
- 自检：生成后逐条核对数字和出处，对不上的标红并重试一次，仍失败就标「待人工核对」
- 记录每次运行的 token、成本、耗时
用 MSFT 和 NVDA 最近一季跑通，把两份笔记给我看。
```

## 阶段 4：评估框架

```
建一个可复现的离线评估（npm run eval:research）：
- 标准答案集：8 家公司 × 2 个季度，每份笔记 10 个关键事实（收入、分部收入、资本开支、毛利率、指引等），数值从 XBRL 自动取，文字类我人工确认
- 指标：数值准确率；出处覆盖率（有出处的陈述占比）；出处准确率（出处里确实能找到该陈述）；「未披露」误报率；有用性（我按 1–5 打分，留打分表）；失败率；P50/P95 延迟；每份笔记成本
- 对比至少 2 个模型（一个便宜的、一个强的），出一张对比表
- 结果自动写进 docs/research-agent.md，带日期和 git commit
指标不达标的地方，列出原因和改进方案，不要为了数字好看去改标准答案。
```
